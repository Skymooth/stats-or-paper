# 审稿、自审与 rebuttal

这一份是"投稿前最后一道工序"。措辞问题见 `style.md`，评分维度见 `rigor-rubric.md`。

---

## 一、五分钟快扫（先自己过一遍）

| 部位 | 检查项 |
|---|---|
| 标题 | 12 词以内？"对象 + 动作 + 限定"都在？记得住吗？ |
| 摘要 | 有具体数字与区间？180 词内？先讲发现还是先讲背景？ |
| 引言 | 前三段内给出主要结果？文献是"织入论证"还是流水账？ |
| 图 1 | 不看正文能否读懂？它是否承载了核心信息？ |
| 贡献清单 | 每条都能对应到一个实验？ |
| 结论 | 一页内？没有引入新结果？ |
| 参考文献 | 有没有一条是你打不开的？ |

**任何一格答"不能"，先修它，别往下读。**

## 二、三视角深审（模拟三位审稿人）

### 审稿人 1：方法学家

- [ ] 核心 claim 的识别 / 验证逻辑，用平实语言说清了吗（先文字，后公式）？
- [ ] 关键假设是什么？被论证了吗？
- [ ] 威胁（混淆、污染、选择性）是否逐条处理？
- [ ] 区间 / 检验是否匹配数据结构（配对？多重比较？分层？）
- [ ] 基线是否同预算调参？
- [ ] 消融是否覆盖所有组件？
- [ ] 有没有 oracle / 上限对照？
- [ ] 样本量是否足以支撑所报的精度？

### 审稿人 2：领域专家

- [ ] 贡献相对于最近 3–5 篇的位置说清了吗？
- [ ] 文献综述是否公平（引了相反结果，而非只引支持的）？
- [ ] 结果是"统计显著"还是"实际重要"？效应量给语境了吗？
- [ ] 设定细节足以复现吗？
- [ ] 结论是否超出证据（overclaim）？
- [ ] 外部效度是否诚实讨论？
- [ ] 数据来源描述足以判断质量吗？

### 审稿人 3：写作批评者

- [ ] 主动语态、现在时（报告结果时）？
- [ ] 具体而非笼统（"提升 3.2 个百分点"而非"显著提升"）？
- [ ] 段首是 claim 而非套话（"值得注意的是…"）？
- [ ] 表能独立读懂（标题、注释、单位）？
- [ ] 图有信息量而非装饰？
- [ ] 每段首句是不是 message？
- [ ] 有没有跨节重复？

## 三、对抗式自审（写完必做）

以"我要拒这篇稿"的心态重读，逐条记下你会写进审稿意见的话，然后：

1. 每条风险标等级：**致命 / 重大 / 次要**
2. 致命的 → 在正文补论证或降低论断
3. 重大的 → 写进"局限"段并说明处理
4. 次要的 → 改文字

**目标不是"没问题"，而是"高风险问题都被显式处理过"。**

### 三个必问的"致命项"

| 问题 | 若是"不能" |
|---|---|
| 如果审稿人只读摘要和引言，他能准确复述你的贡献吗？ | 重写引言，不是重写方法 |
| 你的主结果在最强基线下还成立吗？ | 换基线，或改 claim 的强度 |
| 你的核心机制被移除后，同预算的简单方法能复现提升吗？ | 你的机制没有贡献，是预算的贡献 |

## 五、场所匹配（投哪里）

自问四题：

1. 问题是大范围关心（综合刊）还是子领域关心（领域刊）？
2. 贡献是方法论的，还是既有方法的应用？
3. 设定只对某一场景成立，还是对一般机制说话？
4. 受众有多大？

**决策规则**：如果论文的主要卖点是"在 X 领域有个有意思的结果"，而不是"关于机制的新认识"，投领域顶刊；不必强冲综合顶刊。**一篇被引用的领域论文，胜过一封 desk reject。**

## 六、常见 desk reject 原因（自查）

- 超出页数 / 格式不符（先看 author guidelines，别猜）
- 参考文献里有占位符、有不存在的条目
- 双盲没做干净（致谢、仓库链接、自引措辞）
- 贡献与已发表工作高度重合，且没说明差异
- 没有局限 / 伦理 / 数据可用性声明（该会议必填时）

## 七、rebuttal 写法

1. **逐条编号回应**，先复述审稿人的关切（证明你读懂了）。
2. 三类回应：
   - **接受并已改**：给"原文 → 修改后"的对照
   - **澄清**：给证据（新实验 / 新数字），不要只说"我们认为是这样"
   - **不同意**：给理由与证据，语气克制
3. 每条控制在 3–5 句，不要长篇。
4. 开头用一段话总述"我们做了哪些主要修改"。

**禁忌**：

- 回避某条意见（审稿人会记下来）
- 用"审稿人误解了"开头
- 只承诺不修改（"我们将在最终版中加入…"而没加）
- 逐条反驳却不动一个字—— rebuttal 的目的是让 AC 有理由接受，不是赢辩论

### 一条实务经验

回复里最有力的句子不是"我们不同意"，而是"我们按您的建议补了这个实验，结果如下，因此我们已把 claim 从 X 弱化为 Y"。**降低 claim 也是一种解决**，而且成本最低。
