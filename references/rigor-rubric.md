# 严谨性六维评分

**用法**：定稿前给自己的稿子打分，每维 1–5 分，附优势 / 劣势 / 改法。

**校准**：5 分不是"没问题"，5 分是"确实优秀"；3–4 分是合格稿件的正常区间。**大多数合格稿件应落在 3–4 分。** 给自己打 5 分前先问"我在给谁面子"；打 1 分前先问"我是不是把'可以更好'当成了'根本错误'"。

打分的目的不是自我评价，是**把"我知道哪里弱"变成一份可执行清单**。

---

## 六个维度

| 维度 | 评什么 |
|---|---|
| **D1 证据相关性** | 引用的证据是否**在实质上**支持该 claim，而不只是"有引用" |
| **D2 可证伪性** | 每条 claim 有没有可执行、非平凡的证伪条件 |
| **D3 范围校准** | claim 的强度是否**恰好**等于证据支持的强度（不多不少） |
| **D4 论证连贯性** | 问题 → 缺口 → 洞见 → 方案 → claim → 证据的链条是否通顺 |
| **D5 探索诚实性** | 失败与弯路是否被如实记录（而非只写成功路径） |
| **D6 方法严谨性** | 基线、消融、统计报告、指标与 claim 的匹配、可复现性 |

---

## D1 证据相关性

- **相关性**：实验的设定 / 流程 / 指标，是否真的回答 claim 所断言的？
- **类型匹配**：

| claim 类型 | 线索词 | 需要什么证据 |
|---|---|---|
| 因果 | 导致、使得、因为 | 隔离式消融 |
| 泛化 | 泛化、鲁棒、跨 | 异质测试条件 |
| 改进 | 优于、提升 | 强基线对照 |
| 描述 | 呈现、分布、规律 | 代表性抽样 |
| 限定 | 当…时、仅在 | 明确的边界声明 |

- **充分性**：单次实验够吗？claim 的范围是否要求多次独立实验？

**锚点**

| 分 | 判定 |
|---|---|
| 5 | 每条 claim 都有类型匹配的证据；该多次支撑的都有多次 |
| 4 | 都相关，但有轻微类型错配（如因果 claim 只有相关证据） |
| 3 | 多数相关，1–2 处证据撑不住 claim |
| 2 | 多条 claim 的证据在实质上不回答 claim |
| 1 | 多数 claim 引的实验与其断言无关 |

---

## D2 可证伪性

- **可执行性**：独立研究者能否照做？有没有说清测什么、阈值多少、在什么条件下？
- **非平凡性**："如果方法不 work"是废话；"在 X 换掉后用同一批任务重测，看区间是否含零"才可执行。
- **范围匹配**：claim 说"所有数据集"，证伪条件却只提一个数据集 → 错配。
- **独立性**：不用作者的私有数据 / 系统能测吗？

**锚点**

| 分 | 判定 |
|---|---|
| 5 | 每条都有具体、可执行、范围匹配的证伪条件 |
| 4 | 多数很强，1–2 条含糊 |
| 3 | 好坏参半 |
| 2 | 多数是废话或范围错配 |
| 1 | 证伪条件无意义 |

**合格示例**

```
claim：方法 M 在分布外数据上的提升与其在分布内的提升同量级
证伪条件：在 3 个留出域上，M 与最强基线的差值区间若含 0，或量级低于分布内的 1/3，即 claim 不成立
→ 可执行、非平凡、范围匹配 ✓
```

---

## D3 范围校准

- **过度断言**：用了"所有 / 任何 / 全面领先"这类全称量词，但实验只覆盖窄条件
- **断言不足**：跑出了重要结果，却没有对应的 claim（证据浪费）
- **假设显式化**：关键假设写进正文了吗？有没有设计里隐含但没说的
- **泛化边界**：有没有明确写出 claim **不适用**于什么
- **措辞一致**：用了"倾向于""多数情况下"这类限定，是否与证据强度匹配

**锚点**

| 分 | 判定 |
|---|---|
| 5 | 所有 claim 精确匹配证据范围，假设显式，边界清楚 |
| 4 | 基本校准，个别假设没写 |
| 3 | 有轻微过度 / 不足 |
| 2 | 多处过度断言或有重大未声明假设 |
| 1 | claim 与证据普遍性错配 |

**最容易犯的两条**：把 n=120 的结论写成"普遍规律"；把"预印本报告"写成"研究已证明"。

---

## D4 论证连贯性

- **观察 → 缺口**：缺口是从观察推出来的，还是直接抛出来的？
- **缺口 → 洞见**：核心洞见是否回应了那个缺口？
- **洞见 → 方案**：方法架构是否实现了那个洞见？
- **方案 → claim**：claim 是否覆盖了方案的主要贡献？
- **跨层一致**：引言、方法、实验讲的是同一个故事吗？
- **缺口覆盖**：每个提出的缺口，是否至少有一条 claim 实质性回应？没回应的要么删缺口，要么补 claim。

**锚点**

| 分 | 判定 |
|---|---|
| 5 | 完整逻辑弧，所有缺口都被回应，无矛盾 |
| 4 | 通顺，有个别小断点或一个未回应的缺口 |
| 3 | 大体有流，但层间有脱节 |
| 2 | 问题陈述与 claim 明显错位，或有未解决的矛盾 |
| 1 | 没有连贯线，各节讲不同故事 |

---

## D5 探索诚实性

- **失败记录的质量**：失败原因具体吗？"没 work"是废的；"训练 1,000 步后梯度爆炸发散"是好的
- **决策理由**：为什么选这条而不是另一条？被否掉的替代方案是真方案还是稻草人
- **反向一致性**：有没有某条 claim 在推荐一个已被记录为死路的方向
- **探索广度**：主要设计选择，是否至少考虑过 2 个替代
- **诚实的信号**：一棵没有任何死路、或只有鸡毛蒜皮失败的树，很可疑

**锚点**

| 分 | 判定 |
|---|---|
| 5 | 丰富的失败记录 + 具体失败模式 + 真实负结果 |
| 4 | 较好，个别缺记录 |
| 3 | 有记录但失败描述不具体 |
| 2 | 模板化，像事后补的 |
| 1 | 与 claim 矛盾，或纯属事后合理化 |

**怎么用**：把"我们试过 A，发现三个硬伤；转到 B，又发现它在 C 条件下失效"这段过程写进引言或附录。**审稿人信一个诚实的探索轨迹，远胜信一个平顺的成功叙事。**

---

## D6 方法严谨性

- **基线充分性**：对比对象对吗？够新吗？有"无基线"就下比较性 claim 的吗？
- **消融覆盖**：多组件 claim，至少有一个实验隔离各组件贡献？
- **统计报告**：报方差 / 区间 / 运行次数 / 检验了吗？**只有单次运行就下定量 claim = 危险**
- **指标与 claim 匹配**：claim 说"泛化"，却只用单一测试集准确率衡量 → 错配
- **可复现信号**：模型名、数据版本、硬件、超参够独立复现吗？
- **预算公平**：基线与你的方法是否同预算调参、同算力、同调用次数？

**锚点**

| 分 | 判定 |
|---|---|
| 5 | 基线充分、消融到位、统计严谨、指标精确匹配、完全可复现 |
| 4 | 强，个别实验缺方差 |
| 3 | 够用，但缺部分基线或统计细节 |
| 2 | 明显缺口，比较性 claim 无基线或无消融 |
| 1 | 无基线、无消融、指标不匹配 claim |

---

## 总分与等级

六维取平均：

| 等级 | 条件 |
|---|---|
| **强接受** | 均值 ≥ 4.5 且无维度 < 3 |
| **接受** | 均值 ≥ 3.8 且无维度 < 2 |
| **弱接受** | 均值 ≥ 3.0 且无维度 < 2 |
| **弱拒** | 均值 ≥ 2.0 且（均值 < 3.0 或任一维度 < 2） |
| **拒** | 均值 < 2.0 或任一维度 = 1 |

## 发现清单格式（按严重度排序逐条列）

```
F01 | D6 | critical
  位置：表 2 / 实验 E2
  证据：'未报告随机种子，主指标无法复现'
  观察：主结果未给种子，重跑会得到不同数值
  推理：审稿人无法复现，且数值可被质疑为挑选
  改法：固定种子 + 报 10 次运行的均值与区间
```

**严重度定义**

| 级别 | 含义 |
|---|---|
| `critical` | 根本性缺陷，claim 按现状站不住 |
| `major` | 显著削弱某条 claim |
| `minor` | 不致命但明显 |
| `suggestion` | 改进机会，不算缺陷 |
