# 统计报告与图表规范

这一份管"数字怎么摆出来"。写作腔调见 `style.md`，实验设计见 `rigor.md`。

---

## 一、区间是默认，点估计是例外

| 你要报的量 | 推荐区间 | 备注 |
|---|---|---|
| 比例（错误率、通过率、召回率） | Clopper–Pearson（精确）或 Wilson | 样本小用 CP；大样本可用 Wilson |
| 均值 | bootstrap 百分位 或 t 区间 | 分布偏斜必须 bootstrap |
| 差值 / 提升 | 配对 bootstrap | 配对设计不能忽略配对 |
| 曲线（随参数的函数） | 逐点带 + 整体置信带 | 逐点带会低估联合覆盖，必须说明 |
| 排序 / 名次 | bootstrap 重排 | 名次不稳时直接说"无法区分" |

**写法示例**

```
比例为 0.31（95% CI [0.24, 0.39]，n=120）。
区间宽约 15 个百分点，说明 120 个样本不足以支撑"该比例落在某个窄区间"的强论断。
```

（示例数字，非真实实验。）

**禁止**：只写 `0.31` 而不给区间与 n。

## 二、表格规范

每张表必须**独立可读**：

1. 标题说明"是什么、在什么条件下"
2. 单位写清（%、美元、毫秒）
3. 样本量 n 在表里或表注
4. 最优值加粗，**并说明加粗依据**（按什么指标、是否同一预算）
5. 表注写清：区间类型、显著性标记含义、缺失值处理

**反例**：一张只有数字、没有单位和 n 的表——审稿人必问"这些数怎么来的"。

### 排版

- 用 `booktabs`（`\toprule / \midrule / \bottomrule`），不要竖线
- 数值列右对齐，小数位数全文统一
- 加方向符号：↑ 越高越好，↓ 越低越好

## 三、图规范

1. **能被单独读懂**：标题、轴标签（含单位）、图例齐全
2. **误差必须画**：误差棒或阴影带；注明是哪一种区间
3. **一张图一个 message**：想讲两件事就画两张
4. **颜色可区分**：不要只靠红绿；线型也要区分（Okabe–Ito 或 Paul Tol 配色）
5. **验证灰度可读性**（约 8% 男性有色觉缺陷）
6. **规模诚实**：不要截断坐标轴以便放大差异，除非明确标注
7. 图内不放标题——由图注承担；图注必须自足

### 曲线图的画法

- 横轴：参数取值范围；纵轴：目标量
- 实线：点估计；阴影：置信带
- 多条曲线：不同线型 + 颜色，图注给出每条的 n
- **一定标出你实际选定的那个操作点**（竖虚线 + 数值），否则读者不知道你的单值结论从哪来
- 图注模板：`图 N：<量> 随 <参数> 的变化。<方法> 在 <n> 个 <单位> 上估计；阴影为 95% 置信带（逐点）。竖虚线为本文选定值。`

### 文件格式

矢量（PDF / EPS）优先；位图用 600 DPI PNG。

## 四、假设检验的写法

**报告四件套**：检验名、统计量、p 值或区间、效应量。

```
配对 bootstrap（10,000 次重采样）显示，配置 A 的主指标比 B 高 0.11
（95% CI [0.04, 0.19]），效应量中等（Cohen's d ≈ 0.5）。
```

**禁止**：

- 只写 "p < 0.05"
- 把"未达显著"写成"无差异"
- 做多重比较不校正、也不声明
- 报了大量检验却不说明是探索性的

## 五、异常值与无效运行

必须显式交代，因为处理方式会改变结论：

| 情况 | 处理 | 报告要求 |
|---|---|---|
| 基础设施失败（超时、掉线、额度耗尽） | 单列标记 | 报"剔除前 / 后"两个数，并说明主结果采用哪个 |
| 超长 / 超短轨迹 | 说明阈值 | 报敏感性 |
| 缺失 | 说明是 MCAR / MAR 还是其他 | 报完整案例分析结果 |

**原则**：任何剔除都要能让审稿人复现你的数字。

---

## 六、可复现四件套（缺一不可）

1. **数据**：来源、版本 / 快照日期、获取脚本
2. **代码**：分析脚本；关键函数有注释
3. **随机性**：随机种子；多次运行的方差
4. **环境**：语言与库版本、硬件（若影响结果）

**加分项**：把最终数字与产出它的脚本一一对应（`表 2 ← analysis.py --config full`）。

---

## 七、数字的一致性

定稿前做一次全局核对：

- 摘要里的数字 = 正文 = 表 = 图（四处必须一致）
- 百分比与小数不要混用（0.31 或 31%，全文统一）
- 同一量的有效位数全文统一
- 区间不要"左闭右开"与"闭区间"混写
- 同一个量在不同实验里的定义是否一致（"准确率"在两张表里可能是两种东西）

**这是最容易被抓的低级错误，也最容易让审稿人怀疑严谨性。**
