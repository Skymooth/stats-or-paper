# 严谨性：识别、验证、实验设计与威胁

这一份回答一个问题：**你的 claim 靠什么站住？**

---

## 一、claim 的六种类型与各自的"识别"要求

经济学问"因果效应靠什么识别"，本领域问的是同一个问题的不同形态。**claim 类型不同，需要的证据也不同。**

| claim 类型 | 线索词 | 识别靠什么 | 必须交代 |
|---|---|---|---|
| 我的方法更好 | 优于、提升 | 受控实验 + 同分布评测 | 基线怎么选、是否同预算调参 |
| 我的指标能预测真值 | 预测、相关 | 与真值的对齐 | 真值怎么来的、标注一致性（κ） |
| 我的参数可估 | 可识别、唯一 | 可识别性论证 | 哪些量能识别、哪些不能 |
| 我的方法能泛化 | 泛化、鲁棒、跨 | 分布外 / 跨设定验证 | 划分方式、是否留出 |
| 结构/相关性存在 | 存在、显著 | 统计检验 + 效应量 | 多重性、效应量大小 |
| 只描述现象 | 呈现、分布 | 代表性抽样 | 明确写"本文不估计因果" |

> **写引言第 2 块时**：必须给出**技术原因**，而不只是"效果不好"。技术原因 = 在方法论层面说清"它为什么必然失败"。这才是 insight。

---

## 二、实验设计的四件套

### 1. 基线

- 至少一个**强基线**（不是只和弱基线比）
- 至少一个**单最优基线**（"就用最好的那一个"）
- 说明基线的**调参预算**是否与你的方法相同

### 2. 上限与下界（最常被忽略）

没有上限对照的实验，审稿人会问"你怎么知道这不是方法本身的天花板？"

| 对照 | 作用 |
|---|---|
| Oracle / 理论上限 | 显示可达空间有多大 |
| 随机 / 平凡下界 | 显示下限 |
| 单最优 | 显示"组合到底加了多少价值" |

### 3. 消融

逐项验证每个组件是否必要。**不能只报"全套最好"**——要报拆掉每一项之后的结果。只调超参的"消融"不算消融。

### 4. 复现要素

数据版本、脚本、随机种子、环境。缺任何一项，结果不可复现。

---

## 三、统计推断的四条纪律

1. **报区间**：比例用 Clopper–Pearson / Wilson；均值用 bootstrap 或 t 区间；曲线用置信带。
2. **报效应量**：不写"显著"了事。"显著"只说明区间不含零，不说明重要。
3. **处理多重比较**：比较 k 个配置时，要么校正（Bonferroni / Holm），要么明确写"未校正，仅作探索性"。
4. **小样本不下强结论**：样本小 → 报区间宽度，说"样本不足以区分"，而不是"无显著差异 = 无差异"。

### 阈值的坑（分类器 / 打分器常见）

把连续得分切成二分类时，**阈值是分析者自由选择的**。必须：

- 报出你用的阈值及理由
- 给阈值的敏感性分析（不同阈值下结论是否稳定）
- 如果结论随阈值剧烈变化，那本身是一个发现，要写进去

## 四、威胁清单（写"局限"段直接抄）

| 威胁 | 怎么处理 |
|---|---|
| 测试集污染 / 训练时见过 | 说明数据划分；用新采集或留出集 |
| 对测试集过拟合（反复调参） | 说明调参只用了 dev 集 |
| 选择性报告（只报好看的结果） | 报全部配置；或说明筛选准则 |
| 基础设施失败被算作失败 | 单列"无效运行"，报剔除前后两个数 |
| 标注 / 判定器有偏 | 多标注者 + 一致性（κ）；说明判定模型与版本 |
| 分布偏移 | 说明评测分布与目标分布的关系 |
| 尺度不足（样本量、配置数） | 报样本量；说明结论的适用范围 |
| 版本漂移（依赖外部服务） | 记录版本与评测日期（同一个名字在不同月份不是同一个东西） |

> **规则**：每一条威胁，要么被实验挡住，要么在"局限"里显式承认。**不能沉默。**

---

## 五、写"局限"段的正确姿势

**错误**：只写"我们的方法在大规模场景下可能不适用"（空话，等于没写）。

**正确**：具体 + 可验证 + 指向未来工作。

```
1. 只覆盖 5 个数据集，无法复现"效应随规模增大"的现象。
2. 数据中 9.2% 的记录因运行环境失败被标记为无效；剔除后主指标从 0.58 降到 0.53。
   我们报告两个数字，并说明主结果采用哪一个及理由。
3. 二值化阈值会显著改变结论（阈值 1.0 时 0.58，0.3 时 0.41），
   故以曲线形式报告，而非单一标量。
4. 判定器为单模型，未做人工双标；κ 未知，是本结果的主要不确定性来源。
```

（示例数字，非真实实验。）

**标准**：局限段里每一条，都应当是一个审稿人本来会问、你提前答了的问题。

---

## 六、权衡与成本：审稿人会追问的三件事

方法类与系统类论文，几乎一定会被问：

1. **代价是多少？** 时间、显存、API 费用、标注成本。给绝对值和相对值（相对最强基线贵几倍）。
2. **收益能不能被更简单的东西换到？** 你的机制被移除后，用同预算加算力/加数据能否复现同样的提升？如果不能，你才证明了这个机制必要。
3. **在什么条件下不成立？** 给出边界（规模、预算、分布），而不是"我们相信它一般成立"。

**判据**：如果提升只出现在"你的方法预算更高"的设定里，那不是方法有效，是钱多。
