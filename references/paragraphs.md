# 段落与句子级结构

这一份解决的问题：**为什么一段话读起来"散"、"像拼的"、"不知道在说什么"**。整篇的骨架见 `structure.md`，措辞与腔调见 `style.md`。

---

## 一、写之前先反向推理

动笔之前先回答四个问题，答不出来就别写：

1. 我们解决什么技术问题？为什么还没有成熟解法？
2. 我们的贡献是什么？（新任务 / 新度量 / 新问题 / 新技术）
3. 这条贡献为什么能解决那个挑战？带来什么新洞见？
4. 用前人的哪条线索，把读者引到我们的挑战上？

---

## 二、reverse outlining：写完每节必做

1. 用一句话写下本节论旨。
2. 逐段抽出该段的 **topic sentence**（首句）。
3. 逐段列出它用到的证据 / 论证点。
4. 做两次映射检查：
   - topic sentence → 节论旨
   - 证据 → topic sentence
5. **映射不上的段落，删或改写。** 不要"留着以后再说"——它就是后面审稿意见的来源。

### 做一次的实际感受

抽出 7 个 topic sentence 排成一列，如果读下来像一段能成句的话，结构就是对的；如果其中有一句与前后都不接，那段大概率是从别处搬来的，或者该独立成节。

---

## 三、段落清晰度五问

对每一段问：

1. 这段有没有**一个**明确 message？
2. 首句是否已经说出这段要做什么？
3. 关键名词能否脱离上下文读懂？
4. 每句与上句有明确关系（因果 / 对比 / 递进 / 细化 / 举例）吗？
5. 把这段单独拿出来给外行看，他能说出它在论证什么吗？

五问里 1、2 不过，是结构问题；3、4 不过，是句子问题；5 不过，是整篇的问题。

---

## 四、句间关系要显式，不要"并置"

两类常见病灶：

| 病灶 | 症状 | 修法 |
|---|---|---|
| **并列堆叠** | 连续 4 句都以"此外""同时""另外"开头 | 找出这 4 句里真正的主从关系，改成因果或递进；剩下的删 |
| **跳步** | 读者读完 A 句读 B 句，不知道 B 为什么出现 | 补一句过渡，或把 B 移到它该在的位置 |

关系词（每段给读者一个明确信号）：

- 因果：因此、由于、这导致
- 对比：然而、相反、与此不同
- 递进：更进一步、不仅如此
- 细化：具体而言、即
- 让步：尽管…但…

## 五、贡献段：三种模板

**一条贡献 + 多个优势**（最常见）

```
我们提出 X 框架，用于 Y。
核心思想见图 1。
我们的创新在于 Z。
具体而言，……
与先前方法相比，……（优势 1）
另一个优势是……（优势 2）
```

**两条贡献**（第二条回应第一条留下的子问题）

```
我们提出 X 框架，创新在 Z，见图 1。
具体而言，……（贡献 1）
与先前方法相比，……
然而，还剩一个问题……（子挑战）
为此，我们进一步……（贡献 2）
```

**观察驱动的贡献**

```
我们的创新是……（先给结论）
我们观察到……（直觉动机）
考虑到这一点，我们……（实现）
这带来……并取得……（结果）
```

**不推荐**：只讲抽象洞见、不交代具体机制，靠新术语制造 novelty 错觉。审稿人会判为 shallow / incremental。

## 六、让名词自足

**改前**：该结果优于基线。

**改后**：在 3 个数据集（n=1,200）上，该方法把 F1 从 0.71 提到 0.78（95% CI [0.75, 0.81]），优于最强基线 0.73。

（示例数字，非真实实验。）

**规则**：每句话里出现的"该 / 其 / 这 / 上述"，读者都要能在上一句找到明确所指；找不到就是名词不自足。

**四个高频悬空代词**：这、该、其、此。逐句搜一遍，逐个问"指哪个"。

---

## 七、段内节奏：三个可操作的动作

1. **把结论提到句首。** 中文论文常见"经过实验，我们发现，在大多数情况下，A 优于 B"。改成"A 在多数设定下优于 B（12 个设定中 9 个）"。
2. **每段控制在 4–8 句。** 超过 10 句的段，几乎一定包含两个 message。
3. **公式前后各一句话。** 前一句说"为什么需要这个式子"，后一句说"它意味着什么"。公式本身不解释自己。

---

## 八、标题与摘要的段落级要求

- 摘要：5 句，一句一个动作（做了什么 / 为什么难 / 怎么做 / 证据 / 最该记住的数字）。模板见 `style.md` §五。
- 首段：不要以引用开头，以 claim 开头。
- 每节第一段：给出本节的地图（"本节先…再…最后…"），但只给一句。
