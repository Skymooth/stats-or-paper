# 证据与引用纪律

这一份解决问题的唯一目标：**让论文里每一句话都站得住，且被查时你不会翻车。**

---

## 一、五状态标记（写作期全程使用）

| 标记 | 定义 | 允许怎么用 | 写法要求 |
|---|---|---|---|
| `[正式]` | 同行评议期刊/会议正式发表，有 DOI 或 proceedings 页 | 可作论据 | 正常引用 |
| `[预印]` | 仅 arXiv / Zenodo / 个人站，未过同行评议 | 只作侦察与定位 | 正文写 "(preprint)"，论断降级 |
| `[自算]` | 你跑出的结果 | 可作贡献 | 必须给数据版本、脚本、随机种子、环境 |
| `[推断]` | 你的推论，无直接证据 | 必须显式标注 | 写"我们推测…""一种可能的解释是…" |
| `[待核]` | 来源线索存在，但还没打开核对 | **占位符，不进定稿** | 定稿前必须清零 |

**定稿前自检**：全文搜 `[推断]`，确认没有一处被写成确定语气；全文搜 `[待核]`，必须为零。

---

## 二、三条硬规则

### 规则 1：不许编引用

生成式工具凭记忆给出的文献条目经常出错：文献不存在、作者或年份错、DOI 指向别的文章、文章存在但没说过你引的那句话。写进论文等于学术不端。

**每一条引用的核实流程**

1. 打开它 → 确认标题、作者、年份、出处一致
2. 读摘要与相关段落 → 确认它**真的支持**你这句话
3. 记下它是正式版还是预印本
4. 只有预印本时，把论断改成"有研究报告称…（preprint）"

**禁止**：凭记忆写 DOI；把相似标题的论文张冠李戴；把"综述里提到"当成"原文支持"；把某某博客的转述当成论文结论。

#### 程序化核验四步

```
1. 检索：CrossRef / DBLP / Semantic Scholar / arXiv API / ACL Anthology
2. 双源确认：至少在两个来源里都查到同一条书目信息
3. 抓 BibTeX：通过 DOI 拉取（CrossRef content negotiation）
   https://doi.org/<DOI>  +  Accept: application/x-bibtex
4. 核验断言：打开原文，确认你引的那句话真的在那篇文章里
```

**任何一步失败** → 标 `[待核]` 占位，并明确告诉合作者哪些引用没核实。

#### 三源核验的实战补充

- **DOI 解析**：`https://api.datacite.org/dois/<DOI>`（DataCite 库；Zenodo / arXiv 的 DOI 走这里，查 CrossRef 会 404）
- **Crossref**：期刊 / 会议正式版
- **proceedings 页**：PMLR / OpenReview / ACL Anthology 的页面本身可作核验源

#### 引用幻觉的五个类型（逐类自查）

| 类型 | 表现 | 检测 |
|---|---|---|
| 不存在 | 文献完全编造 | 搜标题，无结果 |
| 元数据错 | 年份 / 期刊 / 作者错 | 与官方页面逐字段核对 |
| DOI 错 | DOI 指向别的文章 | 解析 DOI 看是否为目标文 |
| 断言错位 | 文章存在，但没说过这句话 | 读摘要 + 找到原句所在页 |
| 二手归因 | 把综述中提到的结论当原文结论 | 找到原始论文核实 |

### 规则 2：预印本可以读，不可当依据

- **读**：必须读，否则你会写出"自以为新、其实早有人做"的东西。
- **引**：只在正文以 `(preprint)` 形式出现，且论断强度降低。
- **等**：正式版出来后改引正式版，并检查是否有改动。

**记两本账**：

- **侦察账**（自己看，不进参考文献）：用来判断"我的 delta 还在不在"
- **引用账**（进参考文献）：优先只放正式发表物

### 规则 3：区分"文献结论"与"我们的估计"

| 错误写法 | 正确写法 |
|---|---|
| 研究表明该效应在 0.5–0.8 之间 | 我们的实测为 0.31（95% CI [0.24, 0.39]，n=12 个配置）`[自算]` |
| 已有工作证明该做法总是有效 | 文献 [E007] 在合成数据上报告了方向一致的结果 `[正式]`；我们的复现给出 +0.08（95% CI [0.02, 0.14]）`[自算]` |

## 三、四条不可协商的规则

**核心命题**：**生成的通顺，从来不是证据。**

| 规则 | 具体要求 |
|---|---|
| **① 保密** | 未经授权，不把未发表稿件、审稿材料、受限数据、内部文档送到外部服务。授权不清 → 本地处理，只用最小必要元数据。去标识化需专家复核；"删掉明显的姓名"不算去标识化 |
| **② 不编造** | 引用、DOI、数据值、分母、样本量、单位、效应估计、不确定性、方法细节、软件版本、伦理声明、作者与致谢、资助与 AI 使用披露——**一律不得填空式补全** |
| **③ 证据绑定** | 每条事实性/数值性 claim 绑定到一个已核实的证据 ID；改动措辞后须**重新核验** |
| **④ 科学忠实** | 保留不确定性与替代解释；区分确认性/探索性/描述性/事后分析；方法与结果一致；报告负结果；不把相关写成因果；不把"不显著"写成"等价" |

**遇到缺失，只允许三种状态**：`missing`（缺失）、`unverified`（未核实）、`N/A`（不适用）。**禁止用"听起来合理的套话"填空。**

### 证据绑定的最小实现

```
E 表（来源）：E001 = 作者. (年). 标题. 出处. DOI.
C 表（claim）：C001 = "X 在设定 Z 下优于 Y"
草稿标注：  ... 这一结论 [C001] 由 [E001, E003] 支持
校验记录：  谁核的 / 何时核的 / 核的是原文还是摘要
```

**关键判据**：搜索摘要、生成的总结、记忆、以及别人论文的参考文献列表——**可以帮你发现线索，但不能用来核实 claim**。

## 四、文献综述的写法

### 三步法

1. **分派**：按方法流派分组（不是按时间流水账）。每派写：核心思想 → 代表工作 → 共识 → 局限。
2. **落差距**：用差距矩阵把"最近 3–5 篇"与你的差异列清。
3. **引出 gap**：gap 必须是你贡献的直接前因。

### 差距矩阵（必写）

| 工作 | 正式/预印 | 做了什么 | 没做什么 | 我们补什么 |
|---|---|---|---|---|

**自检**：矩阵里"没做什么"每一行，都要能在贡献列表里找到对应项。找不到 = 该行是凑数，删掉。

### 三种致病写法

1. **只褒不贬**：只引支持你的文献，回避相反结果 → 审稿人一旦发现，信任全失。
2. **笼统归因**："已有大量工作研究 X" → 等于没说，且暗示你没读。
3. **把预印本当既定结论**：这是近两年最容易被抓的点。

## 五、写 gap 之前的查重流程

1. **列出 4–6 个检索词**，覆盖不同词系。同一个概念在不同社区叫法完全不同（例：correlated error / co-failure / ensemble ceiling / model monoculture 指的是同一族现象）。
2. **每个词跑一遍**，记录 top 10 的标题与年份。
3. **确认最近 6 个月**有没有人已经做了你的核心贡献。
4. **对最接近的 3 篇**，读摘要 + 结论 + 局限段，确认它们的边界。
5. 把"他们承认没做的事"抄下来——那通常就是你的位置。

> **教训**：只按一个词系检索会漏。一个方向往往被两三个不同社区同时推进，用词完全不同。

## 六、一致性校验（数值类必做）

建一张"重复数值表"，把同一个量在所有出现处列出来：

```
数值：训练集样本量 = 1,200
出现位置：摘要 / 表 2 / 正文 4.1 / 图 3 图注
核对：四处一致 ✓
```

**常见不一致**：摘要写 31.2%，正文写 0.312，表里写 31%——三个数都对，但口径不同。**全文必须统一。**

## 七、分析类型的标注（写方法节时）

| 类型 | 何时用 | 必须写 |
|---|---|---|
| 确认性 | 先有假设再检验 | 假设是否预注册 |
| 探索性 | 从数据里找规律 | 明确写"探索性"，不宣称验证 |
| 描述性 | 只报告现象 | 明确写"本文不估计因果" |
| 事后 | 看到结果才提假设 | 必须标明，否则是 HARKing |

**不标 = 学术不端风险。**

## 八、报告规范（按研究设计选，只提供指针）

| 设计 | 规范 |
|---|---|
| 随机对照试验 | CONSORT |
| 系统综述 | PRISMA |
| 观察性研究 | STROBE |
| 诊断准确性 | STARD |
| 预测模型 | TRIPOD+AI |
| 定性研究 | SQUIRE |

**注意**：规范只告诉你"该报什么"，不证明质量。**用规范查漏，不当合格证。**

## 九、定稿前的证据审计（五问）

对每一条 claim：

1. 它绑定到哪个证据 ID？
2. 那个证据是谁核的、什么时候核的？
3. 核验时打开的是原文，还是摘要 / 搜索片段？
4. 措辞强度是否超过了证据强度？
5. 如果审稿人要求提供原文那一段，我能在 30 秒内给出来吗？

**五问全过，才准留在正文。**
